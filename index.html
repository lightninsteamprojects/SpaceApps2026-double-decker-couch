Features ▾

These are features that can appear in a star's or object's spectrum. Each image covers a wide range of wavelengths, so you usually won't see individual features in the picture itself, only how bright things look in this band. For distant galaxies, redshift stretches all features to longer wavelengths, so the same feature can land in a different band depending on distance.

Ice and dust features are found by comparing bands. A single photo may not show them clearly.

Red = pixels the detector pipeline flagged (saturation, cosmic rays, bad pixels, ghosts). These are likely artifacts, not real objects.
